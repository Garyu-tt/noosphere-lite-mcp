# Cross-domain discovery pilot — 2026-11-08

This is an **exploratory audit of the author's larger private Noosphere metagraph**, **not a benchmark result for Noosphere Lite 0.3.0**. No private data, encrypted journals, source files, local paths, tokens or server addresses are included.

## Method

- A frozen candidate set contained **46** project-to-project links generated using broad topics such as `gpu_compute`, `network`, `connectome`, `agents` and `knowledge`.
- Preselected seed `20261108`; score-stratified random sample: **8 high** (13 candidates), **8 medium** (14), **8 low** (19), **24** in total.
- A **single AI reviewer** read the linked source artifacts and manually classified each sampled link as:
  - `useful`: identifiable mechanism plus an inexpensive falsifiable compatibility test. **Not** proof of successfully transferring a skill.
  - `plausible`: relevant subject matter but missing compatibility evidence.
  - `noise`: shared vocabulary without a concrete mechanism supported by the cited artifacts.
- The public fixture includes the frozen annotations and concise rationales, but not private original artifacts. Re-running `evaluate.py` reproduces aggregation, **not an independent review of the source evidence**.

## R01 pilot result

| Outcome | Sample count |
| --- | ---: |
| Useful hypothesis | **3 / 24** |
| Plausible / unresolved | **6 / 24** |
| Noise | **15 / 24** |
| Useful proportion in this sample | **12.5%** |
| Possibly relevant (useful + plausible) | **37.5%** |
| Stratum-weighted useful fraction | **11.1%**, exploratory estimate |

No statistical precision or recall claim is made. The annotations are neither independently human-labeled nor peer-reviewed; small strata and subjective criteria introduce uncertainty. Full-population candidate precision would require separately reviewed ground truth. Overall recall additionally requires a discovery-independent inventory of true links, including links *not generated by the algorithm*.

## Known-proposal retrieval check (NOT recall)

The source graph already contained **5 test proposals and 2 documented transfer proposals**. Before R02, the new metagraph had **0 / 7** direct links between their intended entities, despite the proposals being stored elsewhere. R02 materialized **7 / 7 direct links** with explicit `...unverified` status and preserved their proposal nodes.

This demonstrates improved access to *known* proposals only. It is not evidence that new semantic relationships are correctly inferred or that actual cross-domain transfer succeeds.

## Concrete negatives

A link between a **GPU text buffer** in a game-computer emulator and binary matrix multiplication on NVIDIA Pascal is not evidence of a reusable computation, despite both appearing under `gpu_compute`. Rendering Bézier curves in WebGL is likewise not accelerated by a standalone INT8 GEMM solely because both use a GPU.

## Concrete potentially useful tests

1. Compare a sparse neural-state delta update with a BitWeave event kernel under *identical* numerical representation and independent CPU reference.
2. Compare a density/shape-aware dispatcher between different exact CUDA integer kernels on the same hardware and measure *end-to-end* latency.
3. Study bounded jobs / worker-contract semantics across a remote compute broker and an orchestrator (not general GPU virtualization).

All are **unverified proposals**, not demonstrated improvements.

## Safe fix and future work

The private metagraph's R02 patch adds directly grounded proposal nodes/edges, preserving `unverified` statuses, with source DBs read-only and a rebuild/atomic replacement. The public Lite release includes a **separate, optional, read-only lexical suggestions tool**. It neither imports private data nor claims semantic inference. Its synthetic unit tests prevent obvious false positive cases (e.g. one shared generic tag), check that existing relationships are excluded, and ensure suggestions do not mutate encrypted event logs.

A credible next study needs **independent human reviewers**, a larger blinded sample, and pre-registered candidates that include truly unlinked sources. Score sensitivity, inter-rater agreement, precision@k and recall against *independent* gold pairs should be reported, including counterexamples.
